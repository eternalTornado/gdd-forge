# Checklist lite-3-ux-audio — UX, Art and Audio (lite profile)
Applies to: 3_UX Art and Audio.md · Used by: gdd-ux-designer (self-check) and gdd-reviewer.

## Screens & UX
- [ ] LU-01 UX Principles (§3.1) are each testable against a screen, not generic maxims
- [ ] LU-02 Screen Flow & Inventory (§3.2) lists 4–8 screens, each with purpose and key elements
- [ ] LU-03 Every screen traces to a §2.3 mechanic, a D-04 platform requirement, or an explicit brief need
- [ ] LU-04 HUD & Controls (§3.3) names the input model per D-04 and ties HUD elements to §2.3 mechanics
- [ ] LU-05 FTUE & Onboarding (§3.4) states which §2.3 mechanic is taught first and how

## Accessibility, Art & Audio
- [ ] LU-06 Accessibility & Localisation (§3.5) maps every D-39 commitment to a concrete named feature, not a restated brief label
- [ ] LU-07 §3.5 states baseline-only support and is flagged in Open Decisions when D-39 = "None specified"
- [ ] LU-08 Art Style Guide (§3.6) states 2–3 visual pillars traceable to D-07/D-08
- [ ] LU-09 Asset List & Naming Convention (§3.7) states one naming pattern with examples — the single canonical scheme for the whole lite output set
- [ ] LU-10 Game Feel & Juice (§3.8) names feedback per event (hit/success/failure/reward) across shake, particles, haptics, and audio stings — not left generic
- [ ] LU-11 Audio Direction (§3.9) states music style, SFX categories tied to §2.3, and mix priorities

## Anti-fabrication
- [ ] LU-12 No accessibility feature is promised that is absent from D-39
- [ ] LU-13 No audio/visual technology is claimed for a platform not listed in D-04

## Consistency rules
- [ ] LU-14 [Lite rule 4] Every asset row in §3.7 uses the naming convention stated in that same section, applied consistently
- [ ] LU-15 [Lite rule 6] Every UNDECIDED field touched by this file appears in its Open Decisions box
