# Checklist ch12-monetization — Monetisation Ethics
Applies to: 12_Management.md · Used by: gdd-producer (self-check) and gdd-reviewer.
`[R]` = reviewer-only — depends on a chapter written after this one; at self-check count it as n/a (exclude from passed/total), never as a fail.

## Model & Mechanisms
- [ ] MO-01 Monetisation Plan (§12.6) is present only if D-06 ≠ Premium; if D-06 = Premium, it is one paragraph on pricing tier as an Open Decision
- [ ] MO-02 Every monetisation mechanism named uses only entries from D-30
- [ ] MO-03 Ethics limits stated in D-31 (e.g. no pay-to-win, no gacha) are each reflected as a hard constraint in the plan, not just mentioned

## Fairness
- [ ] MO-04 Free-player progression path is described as meaningful, not merely "possible"
- [ ] MO-05 No mechanism is described as creating a pay-to-win advantage when D-31 excludes it
- [ ] MO-06 If gacha/loot box mechanisms are named, disclosure/odds transparency is addressed
- [ ] MO-07 Spending-limit or child-protection measures are addressed only when D-31 or D-40 calls for them
- [ ] MO-14 Monetisation mechanisms described are each mapped to an economy sink defined in ch4 §4.7
- [ ] MO-15 VIP/loyalty-style systems, if described, are stated to avoid competitive power gaps, consistent with D-31

## KPIs
- [ ] MO-08 KPI definitions for monetisation are named (e.g. conversion, ARPPU) without asserting invented target values
- [ ] MO-09 Any numeric KPI target is tagged "(target)" and not presented as an achieved benchmark

## Anti-fabrication
- [ ] MO-10 No monetisation mechanism appears that is absent from D-30
- [ ] MO-11 No pricing or revenue number is stated as fact unless it is present in brief.md

## Consistency rules
- [ ] MO-12 [Rule 7] No monetisation decision states a mechanism or price absent from brief.md
- [ ] MO-13 [Rule 6] If D-06 or D-30/D-31 is UNDECIDED, it is listed in the Open Decisions box
