# Checklist ch05-character — Character Design Consistency
Applies to: 5_Story, Setting and Character.md · Used by: gdd-narrative-designer (self-check) and gdd-reviewer.

## Identity Consistency
- [ ] CH-01 Character names and aliases are spelled identically everywhere they appear in the chapter
- [ ] CH-02 Visual descriptions given for a character in §5.6 do not contradict any mention elsewhere in the document
- [ ] CH-03 Gameplay abilities/stats attributed to a character do not contradict ch4 mechanics they are tied to
- [ ] CH-04 Personality and dialogue style described for a character is consistent across every scene/beat mentioned

## Backstory & Arc
- [ ] CH-05 Relationships and backstories align with the timeline in §5.4
- [ ] CH-06 Each key character's arc (§5.6) has a stated start and end state that is logically reachable
- [ ] CH-07 Each character's gameplay function (§5.6) is stated, not only their narrative role

## Cross-chapter completeness
- [ ] CH-08 Every character listed in §5.6 has a corresponding art entry planned in ch10 §10.3 (when D-21 ≠ None)
- [ ] CH-09 Cast size (3–8 key characters) matches the Depth rule for the resolved D-21 level
- [ ] CH-14 Antagonist and protagonist are both present when D-21 = Light (per Depth rule minimum cast)
- [ ] CH-15 Voice/dialogue style notes are specific enough to differentiate each character (not generic descriptors reused verbatim across multiple characters)
- [ ] CH-16 Animation/interaction requirements mentioned for a character do not contradict requirements stated for the same character elsewhere

## Anti-fabrication
- [ ] CH-10 No character ability or stat is invented that contradicts a mechanic defined in ch4
- [ ] CH-11 No character trait is asserted as a cultural fact without a data file citation

## Consistency rules
- [ ] CH-12 [Rule 4] Every character in §5.6 has an art entry in ch10 §10.3 when D-21 ≠ None
- [ ] CH-13 [Rule 1] Character-related terms match the Glossary in ch3 §3.10
