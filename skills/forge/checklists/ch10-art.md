# Checklist ch10-art — Art Direction
Applies to: 10_Game Art.md · Used by: gdd-art-director (self-check) and gdd-reviewer.
`[R]` = reviewer-only — depends on a chapter written after this one; at self-check count it as n/a (exclude from passed/total), never as a fail.

## Direction & Style
- [ ] AR-01 Art Direction Statement & Visual Pillars (§10.1) restate D-07/D-08, not introduce new style keywords
- [ ] AR-02 Style Guide (§10.2) covers shape language, colour script, materials, and lighting rules as distinct subsections
- [ ] AR-03 Colour script is described per region/act, tied to ch5 §5.3 regions when D-21 ≠ None

## Character & Environment Art
- [ ] AR-04 Character Art (§10.3) has one entry per character listed in ch5 §5.6, covering silhouette, palette, and costume rules
- [ ] AR-05 If D-21 = None, §10.3 covers only the player avatar and enemies, per the Depth rule
- [ ] AR-06 Environment Art (§10.4) has one entry per region (ch5 §5.3) or zone (ch6)

## Production
- [ ] AR-07 Props, VFX & Animation principles (§10.5) are stated as principles, not an asset list
- [ ] AR-08 UI Art (§10.6) cross-references ch7 §7.4 rather than restating the HUD design
- [ ] AR-09 Marketing & Store Art needs (§10.7) are listed separately from in-game asset needs

## Pipeline & Asset List
- [ ] AR-10 Asset Pipeline & Naming Convention (§10.8) states a naming pattern with at least one worked example
- [ ] AR-11 Asset List (§10.9) table has id, type, name, source chapter, priority, and notes filled for every row
- [ ] AR-12 Every asset row in §10.9 follows the naming pattern defined in §10.8

## Anti-fabrication
- [ ] AR-13 No art style reference or IP is claimed as inspiration beyond what D-07/D-13 name
- [ ] AR-14 No image, mood board, or reference asset is claimed to have been generated (Reference & Mood Board §10.10 is text-only by contract)

## Consistency rules
- [ ] AR-15 [Rule 4] Every character in ch5 §5.6 has a corresponding entry in §10.3 when D-21 ≠ None
- [ ] AR-16 [Rule 5] §10.8 adopts ch7 §7.11's naming pattern verbatim (extensions allowed, no competing scheme) and every row in §10.9 follows it
