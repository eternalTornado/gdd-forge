Craft guidance — `1_Concept.md` (lite)

Write pillars last, after the feature set and exclusions are clear, then check each one against every `D-43` must-have and `D-30` mechanism: a pillar whose forbid clause blocks something the brief requires is a defect in the pillar, not a note for later — reword it before moving on.

Order feature priorities so a P0 never depends on a P1 or P2 — check the dependency chain, not just the individual tags.

Glossary capitalisation and spelling here are binding on every file that follows: other agents copy your terms verbatim, so settle each one deliberately rather than typing the first spelling that comes to mind.

Session length and run length are different numbers — a mobile session can hold several runs. Keep the two separate everywhere either appears.

Comparables belong in a table (comparable · borrow · avoid), not a paragraph of enthusiasm — a comparable with nothing to avoid reads as fan praise, not analysis.

This file is the anchor: every other lite file re-reads it in full. Before finalising, reread your own draft once and cut any sentence that is not a decision, a pillar, a defined term, or a scope count — nothing else earns its place here, since every extra sentence is one more thing three other agents now have to reconcile against.
