Craft guidance — `3_UX Art and Audio.md` (lite)

Start from the player choices file 2 names, not from a blank screen list — every choice needs a home screen before you design anything else, and a choice with no screen is a gap you created, not one the brief left open.

Walk the flow backward from the end-of-run screen to every one of those homes — this is the path a real player actually takes after a run ends, and it's the fastest way to notice a choice with no reachable screen.

Never mention a screen or an asset in passing — if it isn't a row in the screen inventory or the asset list, it doesn't exist yet; add the row or cut the mention.

When you need a gameplay rule, a tunable or a number, point to file 2's section instead of restating it — a restated number is a number that can drift out of sync with the one that actually governs the game.

Write the game-feel/juice section as a table, not a mood paragraph — implementers need a feedback channel and a trigger per row, not an adjective.
