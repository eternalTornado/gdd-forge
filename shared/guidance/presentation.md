# Guidance — presentation systems

Art and audio direction, game feel, asset list.

- D-07 and D-08 decide the style; never switch styles because another looks more marketable.
- State what the style is for: readable threats, interactables and safe zones at a glance. Give the rule that ties palette to meaning ("warm = safe, cold = hostile"), not only swatches.
- Game feel as a table: event · visual · audio · haptic · tunable timing. Implementers need a channel and a trigger per row, not adjectives.
- Audio: music style and how it adapts, SFX categories, voice delivery if any, mix priorities.
- Asset list is a minimum: cover categories (character, environment, prop, VFX, UI, audio) before going deep in one. Use one naming pattern, stated once with 2–3 examples.
- Fidelity follows D-04: no high-poly pipeline for a mobile-only game; no invented polycount or texture budgets without a data file.
- Reference and mood are described in words; never generate or embed images.
