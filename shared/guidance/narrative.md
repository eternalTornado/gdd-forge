# Guidance — narrative systems

Story, setting, characters, how story is delivered.

- D-21 sets how much story exists. Writing a full cast for Light framing is scope the user never granted.
- Setting must intersect gameplay: say how the world explains the rules the mechanics docs state.
- Name the delivery mechanism first (barks, cutscenes, codex, environmental storytelling, none); it decides what UI and content must support.
- Prefer environmental storytelling for Light and Medium weight, and make each hook concrete enough for level and art work.
- Every character has a gameplay function ("grants the double-jump in world 2"), not only a personality.
- Plot beats go in a table and mark where each beat meets progression.
- Factions only if the plot needs opposing groups; one honest line beats an empty faction table.
- Keep cultural and sensitivity notes for the D-05 audience; use only the cultural data you were given, never claims from memory.
